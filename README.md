# Каталог приложений

Учебное Android-приложение на Jetpack Compose с каталогом приложений. На главном экране размещены акцентный тулбар и вертикальный список карточек с иконкой, названием, описанием и категорией. Данные каталога находятся в `data/AppCatalogRepository.kt`, модель — в `model/AppInfo.kt`, а экран и его компоненты разделены в пакете `ui`. Тексты, цвета, размеры и векторные иконки вынесены в Android-ресурсы; для светлой и тёмной тем предусмотрены отдельные палитры.

Чтобы запустить приложение, откройте проект в Android Studio и запустите конфигурацию `app` на эмуляторе или Android-устройстве.
